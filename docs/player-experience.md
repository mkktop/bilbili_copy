# 播放页

普通观看模式保留应用窗口标题栏。视频下方提供信息、互动、下载、评论和 AI 章节，选集与推荐侧栏可收起；宽度不超过 900px 时默认收起侧栏。点「沉浸模式」扩大画面，点「选集 / 推荐」返回普通布局并展开侧栏。

底部控制栏提供播放/暂停、下一集、音量、进度、弹幕、画质、倍速和全屏。播放过程中无操作时自动隐藏，暂停、操作菜单或键盘聚焦时保持可见。进度条支持拖动及键盘方向键，悬停预览使用实际进度轨道定位。

字幕、系统画中画、应用内小窗位于「播放设置」。系统画中画只包含视频本身，字幕和弹幕请使用应用内小窗观看。普通/沉浸/小窗切换复用相同的视频元素；所有全屏入口均包含弹幕、字幕与自定义控制栏。

快捷键：空格播放/暂停，左右方向键前后 5 秒，上下方向键调节音量，M 静音，D 弹幕，F 全屏。输入框、进度/音量滑块和按钮保留自身键盘行为。小窗模式仅在播放器内聚焦时响应播放快捷键，避免影响底层页面。

Esc 按顺序关闭菜单、退出全屏、收起侧栏、退出沉浸模式，再返回。分P与跨视频列表均支持下一集及可关闭的自动连播；视频详情页每个分P另有独立播放按钮，不影响下载勾选。

切换画质保留暂停状态、倍速和位置，优先使用新视频与音频的分片索引定位，并为编码延迟预留解码前滚；索引不可用时回退顺序填充。最终播放失败可重新获取流地址并重试，或选择较低画质。

开发验证：

```sh
pnpm typecheck
pnpm build:renderer
pnpm exec playwright install chromium
pnpm test:player
```

测试直接挂载生产组件，使用本地 H.264/AAC 分片验证布局、全屏、画质切换、快速操作、进度、小窗、连播、下载参数和错误恢复。具体夹具与复现命令见 [tests/player](../tests/player/README.md)。Windows WebView2、真实 B 站 CDN、会员权限、系统画中画和高分辨率硬解仍需在 Windows 桌面环境验收。
